# Media for the RoFacto review

The result videos and method overview come from Byungjun Kim, Taeksoo Kim, Hyunsoo Cha, and Hanbyul Joo's [official RoFacto release](https://bjkim95.github.io/rofacto/), accompanying [*Robot-Factored World Models via Robot Rendering*](https://arxiv.org/abs/2607.22535v1). Retrieved September 10, 2026.

The Markdown editions show animated GIF previews linked to the original videos. The HTML reading editions play labeled local MP4 copies with pause, seek, and fullscreen controls. The copies retain the complete released clips at their original frame rates and playback speed. Presentation changes consist of resizing and labels placed outside the original imagery. The GIF previews sample at 8 fps. No image region has been removed or retouched.

For the two motion-gap comparisons, we placed the authors' separate clips side by side with synchronized starts. These are colored robot outlines over observed footage, not videos generated by three competing models. The observed background provides a visual reference; it is not a privileged future-video condition supplied to RoFacto.

## Rebuilding the reading editions

After editing either Markdown document, run:

```sh
python3 robotics_ai/media/rofacto/render_reading.py
```

The renderer uses Python `markdown-it-py` and Matplotlib, embeds equations and the existing flowchart as SVG, and prefers the local labeled MP4s. No external JavaScript, fonts, or math service is required for reading or playback.

To regenerate the labeled video assets from the original release, use Python with Pillow, `ffmpeg`, and `ffprobe`:

```sh
python3 robotics_ai/media/rofacto/build_media.py --cache /tmp/rofacto-media
```
