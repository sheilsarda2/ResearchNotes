Implement a durable local output collection target in this Luigi checkout. A task currently has to assemble multiple files itself, and another task can observe an incomplete or mixed collection. Add `luigi.LocalGenerationTarget` and export `GenerationIntegrityError` (a ValueError subclass) and `GenerationConflictError` (a RuntimeError subclass) from both `luigi` and `luigi.generation_target`.

This is a POSIX local-filesystem feature. Keep existing LocalTarget, Task and worker behavior compatible. A target returned from a real Task.output() must work with normal completion checks, local/multiprocess workers, dependency scheduling, and downstream consumers. Do not change test infrastructure or install an alternative Luigi package.

Public API:

* `LocalGenerationTarget(root, members)` is a Luigi Target. `root` is a filesystem path or PathLike, exposed as absolute `target.path`. `members` is a nonempty dict mapping nonempty string logical names to unique canonical relative paths (string or PathLike). Reject absolute paths, empty components, dot/parent components, backslashes, NULs, duplicate paths, and file/directory prefix collisions with ValueError. Copy caller inputs; `target.members` returns a defensive dict copy.
* `target.current_generation` returns the committed generation ID or None before any publication. An ID is a nonempty opaque string usable as `expected_generation`; users must not need to interpret it. `exists()` verifies committed content and returns a bool. Reading an absent store must not create it.
* `target.write()` returns a single-use writer context. On context entry it captures the current generation. `target.write(expected_generation=id)` instead compares with that explicit ID, and explicit None means the store must still be unpublished. On successful exit, compare the expected and actual current IDs atomically with publication. If unequal, raise GenerationConflictError and leave the winning generation untouched. Two writers entered against the same current ID cannot both publish. No unconditional overwrite mode is required.
* Within the writer, `writer.open(name, mode='w', format=None)` returns a stream. Support UTF-8 text `w` and raw bytes `wb`; reject other modes. Each name may be opened at most once using this method. Unknown names raise KeyError. Optional Luigi `format` delegates to that format's pipe_writer over a binary output stream, with the format's usual text/bytes semantics. `writer.path(name)` supplies a staged path, creating necessary member directories, for external programs that write files themselves. This is an alternative to open for that member, and not an implicit commit. `writer.generation` is None until successful publication and then gives the published ID. Writer path/open cannot be used outside its context, and a writer cannot be entered twice.
* Successful writer exit requires every declared member to exist as a regular file, no undeclared payload files, and every stream opened through writer.open to have been closed. Missing members, symlink members/directories, malformed staging content and open member streams raise GenerationIntegrityError. An exception in the body aborts publication and propagates. Close owned streams and remove the abandoned staging files on ordinary failure. File data and publication metadata must be flushed durably before reporting success. A terminated process may leave garbage, reclaimed by prune.
* `target.snapshot()` returns an already-pinned snapshot, also usable as a context manager. No current generation raises FileNotFoundError. A corrupt committed generation raises GenerationIntegrityError. `snapshot.generation` remains stable; `snapshot.open(name, mode='r', format=None)` supports UTF-8 text r and raw bytes rb, and optional Luigi pipe_reader formats. Unknown names raise KeyError and unsupported modes raise ValueError. `snapshot.path(name)` gives an immutable member path for external readers. `snapshot.close()` is idempotent; path/open/enter after close raise ValueError. Callers must close snapshots; automatic garbage-collection finalizers are not required. Opening a snapshot validates every declared member; opening a member later revalidates that member before returning its stream.
* `snapshot.manifest` returns a defensive dict copy; `snapshot.manifest_path` is the path to its UTF-8 JSON manifest, for external verification. The manifest has `version: 1`, `generation: <ID>`, and `members: {<name>: {path: <declared relative path>, size: <nonnegative integer byte count>, sha256: <lowercase hex SHA-256>}}`. Unknown/mismatched versions or identity, missing/mismatched members, invalid metadata, missing files and content changes are integrity failures. Diagnostics for a member failure must identify its logical name or path. Malformed JSON and duplicate JSON keys are rejected. Booleans are not integer sizes or versions. The target's declared member mapping must match the committed mapping.
* Expose `<root>/CURRENT` as an atomically replaced UTF-8 JSON administrative pointer with at least `version: 1` and `generation: <ID>`. Additional metadata is permitted. Missing CURRENT means no committed generation; malformed or invalid CURRENT is an integrity failure. Staging/final-directory presence alone must never make the target complete. Publication and failure recovery are tested by interrupting or failing `os.replace` for CURRENT immediately before and immediately after replacement; after a fresh process reopens, either the entire old or entire new collection must be valid, never a missing or mixed one. Do not roll back by deleting a generation that CURRENT already names. An unsuccessful call may already have published if the interruption occurred after this atomic switch.
* `target.prune(keep=1)` retains the current generation, the newest `keep` committed generations, every actively pinned generation, and active staging writers. `keep` must be a nonnegative integer (not bool). It reclaims older unpinned generations and abandoned staging/final generations from failed or terminated writers. It returns the removed final-generation IDs in sorted order, without staging IDs; repeated calls are safe. Reader/writer pins must be interprocess locks released by OS process death, not permanent marker files. Pruning may run concurrently with publication, snapshot acquisition/closing, and another prune. A process holding an old snapshot must still read it after later commits and pruning. After that process exits or closes its pin, a later prune can reclaim it.
* Managed roots, directories, members, manifests, CURRENT and lock paths must not be followed through symlinks. Report observed structural corruption as GenerationIntegrityError (exists returns false). Prune must never remove data reached through an external symlink. This does not require defending against an adversary rewriting directory entries between individual system calls. Genuine permissions or unrelated I/O failures propagate; exists must not turn all exceptions into false.

Keep source changes integrated and documented. The result should support repeated generation replacement and process restart without requiring a running scheduler or an external service. No remote/object-store implementation, Windows support, distributed locking, arbitrary generator serialization, or journal daemon is requested.

Evaluation uses a fresh offline container with the pinned dependencies. Only `/workspace/repo/luigi/` is transferred as the submitted implementation. Keep runtime feature code inside that package; upstream tests and documentation may also be edited for development but do not replace the independent verifier.
