The current inventory identifies **147 explicit leaves** and **37 automatic
sources or reservations**. Their existing Zenoh evidence totals approximately
**19.29 MiB uncompressed**: 7.80 MiB explicit and 11.49 MiB automatic. This
already includes the 3.14 MiB reviewed task copy. The nine pending paired
source copies add at least **22.04 MiB**, measured from the saved submissions;
future verifier/review logs and compressed archive size remain unknown. These
are filesystem-stat estimates, not final archive measurements.

Do not pass entire control/review/regrade parent directories as explicit
`--supporting-source` arguments. The packager removes nesting among automatic
sources before appending explicit ones, then rejects destination collisions.
An explicit parent therefore conflicts with an automatic child. The JSON
lists maximal disjoint sibling files/directories instead. Recompute these
complements from the actual final mapping and quality/regrade output identities
after completion; active files can grow and new children can appear.

The captured runtime's `immutable-tooling-v1/files/research` convenience symlink
is deliberately excluded. Include `manifest.json` and `files/scripts/`; the
separate execution-context and source/task evidence explain the relationship.
Historical snapshot `original` pointers resolve through their included immutable
copies. Original model trials remain in the strict pack's existing `jobs/`
tree; final/parent tasks resolve through its `samples/` and `archive/` mapping.
No Docker image export, host environment, credentials, private `.build`
intermediates, or supplied restaurant tree is added.

This inventory itself lives under `packaging/`, which the frozen packager
rejects as a supporting source. Keep it with packaging receipts or in a separate
supporting document archive; do not change that restriction. Final assembly
