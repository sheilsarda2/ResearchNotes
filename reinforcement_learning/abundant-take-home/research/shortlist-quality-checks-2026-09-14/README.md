# Required Harbor quality reviews

These are separate task-quality reviews of the three proposed final tasks: Rerun chunk optimizer, Burn reader v4, and Zenoh timestamp instrumentation v3. They are outside the scored sweep and do not change its cells, trial counts, task files, verifier rules, or budgets.

The user-authorized evaluator is `mini-swe-agent` 2.4.6 with routed `anthropic/claude-sonnet-5`, high effort, one attempt per task, sequentially. A dedicated local concurrency limit of one shares the existing global cap of 14 and memory/pressure/startup guards. The generated Harbor quality-review task retains its default 1800-second agent and 120-second verifier limits; these are review limits, not benchmark task changes. Public gateway endpoints are agent environment settings. The existing credential is read through the standard repository environment convention and never put in saved CLI arguments or configurations.

`reviews-002/summary.json` is the authoritative current run status. Each successful review records the exact original task checksum, generated wrapper checksum, raw result/score/report/trajectory hashes, evaluator usage and step counts, agent preflights, cleanup before grading, actual captured runtime imports, and shared-slot acquire/release evidence. Each `*-proof/` directory preserves the complete generated wrapper and an unchanged byte-identical copy of the reviewed task, plus the default rubric and template/source hashes. Harbor deletes its own temporary wrappers after each review; these separate captures retain the input evidence.

A review reward of 1 means the agent produced a schema-valid report. It does **not** mean all rubric criteria passed. The per-task `criteria_fail` entries and underlying `check_report.json` are the substantive findings. Any potential task/grader problem requires review before edits; this harness never changes the reviewed task.

`immutable-tooling-v1/` is a frozen byte-identical capture of the standard runner and its complete local dependency set. Its `research` symlink preserves existing read-only verification path resolution. Later live source changes cannot alter the captured execution. `execute_quality_check.py` is a separate wrapper which explicitly declares model execution, captures ephemeral review inputs, and audits actual loaded modules. It does not reuse the zero-model oracle/no-op proof claim.

`reviews-001/` preserves an initial evidence-wrapper preflight failure: a rubric constant was referenced on a reexport module rather than its defining module. All three processes stopped before runtime installation, shared-slot admission, agent setup, or model calls. Original attempt sources and hashes remain saved there. The corrected wrapper passed the installed-Harbor offline inspection in `offline-preflight/` before `reviews-002` was launched; no paid attempt was repeated.

All three reviews have completed. Rerun and Burn each pass11/11 rubric criteria; Zenoh passes10/11 with `behavior_in_tests` failing. `zenoh-coverage-assessment.json` confirms missing direct boundary/malformed-stack and admin Receive tests while noting existing normal codec and public invalid-enum coverage. No mutation test was run and no task or grader was edited. The separate `completed-review-audits/` files verify usage, native/ATIF linkage, pre-verifier snapshots, and raw hashes. Rerun's reviewer explanation overstates whole-agent network isolation; that wording caveat is retained. Total reported review cost is $2.5620379 across143 logical model calls.
