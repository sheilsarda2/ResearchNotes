This isolated synchronous candidate fixes the two reproduced local failures in the frozen baseline. It passes 19 offline regressions using the same LiteLLM 1.100.1 source and captured Mini 2.4.6 model code. It has **not** been deployed or tested against the provider.

`checked_anthropic_iterator.py` subclasses LiteLLM's existing decoded-event iterator. Its HTTP/SSE/JSON parsing remains unchanged. The adapter buffers each signed thinking block until its block stop, emits the exact text/signature once, and preserves redacted blocks. A small normalization at the existing thinking collector also retains empty signed blocks. It holds the final finish/usage chunk until a decoded `message_stop` arrives, because LiteLLM otherwise stops collecting at the finish reason. Missing final provider usage, unclosed content, and premature EOF raise before Mini accepts or counts a response.

The tests cover all prefixes of an incomplete response; explicit transport/SSE errors; missing usage and terminal events; fragmented tool JSON and signatures; signed, empty, multiple, and redacted thinking blocks; multiple text blocks; second-turn message ordering against the existing non-streaming Mini path; tool-call and length finishes; input/output/cache counts; and synthetic cost parity. The multi-block artifact retains both paths and their equal next-turn request messages. The non-streaming tool object includes a content-block `index` metadata field absent from streaming; normalized tool arguments/actions and subsequent wire messages match. This existing metadata difference is not described as byte-identical full trajectories.

The adapter is version/hash bound and only installed temporarily by an explicit context manager inside the offline test process. That context manager patches process-global class/method references, so it is an experiment, not a production integration. Async calls are explicitly unsupported. No Anthropic SDK was installed in either examined environment; this prototype reuses the installed LiteLLM parser instead of adding an SDK or new SSE parser.

Limits remain: synthetic signatures are checked for exact preservation, not cryptographically verified; Python differs from live agents; the tariff is synthetic; no real connection lifetime, cancellation/deadline, retry integration, concurrent calls, provider route, heartbeat, or gateway behavior has been validated. A complete `message_stop` is the accepted semantic boundary; trailing bytes after it are not consumed by the stock outer collector. Route support and relief of the roughly 291-second failure remain unproven. Live task instructions, model/effort/output limits, current attempts, and installed packages remain unchanged.
