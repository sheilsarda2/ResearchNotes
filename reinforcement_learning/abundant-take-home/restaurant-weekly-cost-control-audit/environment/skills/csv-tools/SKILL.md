# CSV Tools

Use this skill for reliable CSV pipelines.

## Checklist

- Validate required columns before calculations.
- Parse numeric fields explicitly.
- Normalize date formats consistently.
- Sort output rows by stable business keys.

## Typical Operations

- Group by and aggregate totals.
- Join CSV sources by identifiers.
- Export deterministic output order.
