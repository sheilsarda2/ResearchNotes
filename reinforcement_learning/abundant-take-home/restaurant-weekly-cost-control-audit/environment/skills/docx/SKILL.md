# DOCX Editing

Use this skill for `.docx` report generation tasks.

## Typical Workflow

1. Create or load a document.
2. Define heading hierarchy.
3. Insert sections and tables.
4. Apply styles consistently.
5. Save once at the final output path.

## Good Practices

- Keep heading levels consistent.
- Keep table schemas explicit.
- Validate output opens correctly in Word/LibreOffice.
