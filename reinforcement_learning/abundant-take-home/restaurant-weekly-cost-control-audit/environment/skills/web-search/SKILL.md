# Web Search

Use this skill for external research tasks.

## Workflow

1. Query targeted sources.
2. Prefer official and primary references.
3. Capture links and retrieval date.
4. Separate sourced facts from inference.

## Quality Rules

- Avoid single-source claims for critical points.
- Prefer reproducible citations.
