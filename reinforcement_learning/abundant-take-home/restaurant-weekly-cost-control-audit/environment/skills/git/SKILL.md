# Git Workflow

Use this skill for routine source-control operations.

## Core Commands

- `git status`
- `git diff`
- `git add <path>`
- `git commit -m "message"`
- `git log --oneline --decorate -n 20`

## Safety

- Review diffs before commit.
- Keep commits scoped to one logical change.
- Avoid force-pushing shared branches unless explicitly needed.
